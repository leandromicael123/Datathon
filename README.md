# Datathon

Bem-vindo ao repositório do Datathon!

## Sobre o projeto

Este projeto foi desenvolvido para participação em um Datathon, focando em análise de dados e modelagem preditiva utilizando Python e Jupyter Notebook.

## Estrutura do repositório

- `notebooks/`: Contém os notebooks utilizados na análise e modelagem.
- `data/`: Dados utilizados no projeto.
- `scripts/`: Scripts auxiliares em Python para limpeza, análise e visualização dos dados.
